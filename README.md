Mood-Based Motivation App
Let your mood decide your motivation. 🌟

A simple web project that changes background images, quotes, and styles based on the user's selected mood — built with HTML, CSS, and JavaScript.

* Features
Select your current mood (Happy, Sad, Lazy, Energetic).

* Dynamically updates:
Image
Motivational Quote
Background Color
Clean, responsive design.

Fully built with HTML, CSS, and JavaScript — no frameworks!

🛠️ Tech Stack
HTML5
CSS3
JavaScript (ES6+)
